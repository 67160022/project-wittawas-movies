# คำตอบข้อที่ 1

สำหรับ Movies API เลือกฟิลด์ `title` เป็นฟิลด์ที่ต้องไม่ซ้ำ (Unique) เพราะต้องการป้องกันการเพิ่มข้อมูลหนังเรื่องเดิมซ้ำในระบบ ทำให้ข้อมูลมีความถูกต้องและง่ายต่อการจัดการ

เมื่อมีการส่ง `POST` แล้วพบว่า `title` ซ้ำกับข้อมูลเดิม ควรตอบ **409 Conflict** เนื่องจากคำขอมีรูปแบบถูกต้อง แต่เกิดความขัดแย้งกับข้อมูลที่มีอยู่แล้วในระบบ ส่วน **400 Bad Request** ใช้สำหรับกรณีที่ข้อมูลที่ส่งมาไม่ถูกต้อง เช่น ส่งข้อมูลไม่ครบหรือรูปแบบข้อมูลไม่ถูกต้อง

# คำตอบข้อที่ 2

หากต้องการเพิ่ม Endpoint สำหรับแก้ไขข้อมูลเพียงบางฟิลด์ โดยไม่กระทบกับ `PUT` ที่มีอยู่ ควรใช้ **HTTP Method `PATCH`** และใช้ Route เดิมคือ

```http
PATCH /api/v1/movies/:id
```

`PUT` ยังคงใช้สำหรับแก้ไขข้อมูลทั้งรายการ โดยผู้ใช้ต้องส่งข้อมูลครบทุกฟิลด์ ส่วน `PATCH` จะอัปเดตเฉพาะฟิลด์ที่ส่งมา เช่น `title`, `director` หรือ `releaseYear` ทำให้สามารถแก้ไขข้อมูลบางส่วนได้โดยไม่กระทบกับการทำงานของ `PUT`
