# URI Schema

| Method | URI                   | คำอธิบาย                  | Status Code ที่ต้องจัดการ |
| ------ | --------------------- | ------------------------- | ------------------------- |
| GET    | `/api/v1/movies`      | ดึงข้อมูลหนังทั้งหมด      | 200                       |
| GET    | `/api/v1/movies/{id}` | ดึงข้อมูลหนังตามรหัส (id) | 200, 404                  |
| POST   | `/api/v1/movies`      | เพิ่มข้อมูลหนังใหม่       | 201, 400, 409             |
| PUT    | `/api/v1/movies/{id}` | แก้ไขข้อมูลหนังทั้งรายการ | 200, 400, 404             |
| DELETE | `/api/v1/movies/{id}` | ลบข้อมูลหนัง              | 200, 404                  |
| PATCH  | `/api/v1/movies/{id}` | แก้ไขข้อมูลหนังบางส่วน    | 200, 404, 409             |
